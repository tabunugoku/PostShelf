FEATURES

整理に必要な機能Everything you need to sort

見た目は X に近く、操作は迷いません。It looks like X, so there is little to learn.

自由なフォルダFolders your way

名前・アイコン・色を自由に選べます。1 つのポストを、複数のフォルダに入れることもできます。Choose any name, icon and color. One post can go into several folders.

x.com でそのまま保存Save right on x.com

ブックマークボタンの横に、フォルダを選ぶ小さなメニューが出ます。画面を離れずに分類できます。A small folder menu appears next to the bookmark button, so you can sort without leaving the page.

3 つの表示Three views

X 風のカード、リスト、グリッドを切り替えられます。サイドパネルでも使えます。Switch between X-style cards, a list and a grid. It also works in the side panel.

探しやすいEasy to search

本文と投稿者の検索、並べ替え、「画像あり」「動画あり」「リンクあり」の絞り込み、最近 7 日のスマートビュー。Search text and authors, sort, filter by images, videos or links, and use the smart view for the last 7 days.

動画と画像を見分けられるVideos and images at a glance

動画には再生ボタンと「動画」の札、複数枚の画像には枚数の札が付きます。Videos get a play button and a label, and multi-image posts show how many images they have.

長いポストも全文でLong posts in full

たたまれたポストは、保存するときに裏のタブを短く開いて全文を読み取ります (設定でオフにできます)。PostShelf では、たたむ・広げるを切り替えられ、本文中のリンクも開けます。When you save a collapsed post, PostShelf briefly opens it in a background tab to read the full text (you can turn this off in Settings). You can collapse or expand posts, and links in the text open normally.

複数アカウントMultiple accounts

X のアカウントごとに、フォルダとポストを分けて管理します。Folders and posts are kept separately for each X account.

取り込みと書き出しImport and export

既存のブックマークは、確認のうえで自動取り込みできます (任意)。JSON でのエクスポート / インポートにも対応しています。Import your existing bookmarks automatically after a confirmation (optional), and export or import your data as JSON.

データは端末の中だけYour data stays with you

保存先はブラウザの中だけ。外部への送信も、解析も、アカウント登録もありません。Everything is stored inside your browser. No uploads, no analytics, no sign-up.

フォルダの色は 8 色 (と色なし)8 folder colors (or none)

アイコンも、どの色でも選べます。Any icon can use any color.

INSTALL

インストールの手順How to install

Chrome ウェブストアでは配布していないため、ZIP を取得して手動で読み込みます。4 ステップ、約 3 分です。PostShelf is not on the Chrome Web Store, so you download a ZIP and load it by hand. Four steps, about 3 minutes.

1

ZIP を取得Get the ZIP

GitHub の Releases から postshelf-1.1.2.zip (最新版) をダウンロードします。Download postshelf-1.1.2.zip (the latest version) from GitHub Releases.

2

展開して置くUnzip it

固定の場所のフォルダに展開します。削除や移動をしない場所にしてください。Unzip it into a folder you will keep. Pick a place where it will not be deleted or moved.

3

デベロッパーモードDeveloper mode

chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。Open chrome://extensions and turn on "Developer mode" at the top right.

4

読み込むLoad it

「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。Choose "Load unpacked" and select the folder you unzipped.

更新するとき: 先に設定の「データの保存と移行」からエクスポートで保存してから、同じフォルダに新しい版を上書きし、「再読み込み」を押します。拡張機能は削除しないでください (保存したデータも消えます)。Updating: first export your data in Settings ("Backup and transfer"), then overwrite the same folder with the new version and press "Reload". Do not remove the extension, or your saved data goes with it.

HOW TO USE

使い方How to use

場面ごとに、手順を示します。Steps for each common task.

ポストを保存するSave a post

  1. x.com で、ブックマークボタンの横にある PostShelf のボタンを押します。On x.com, press the PostShelf button next to the bookmark button.
  2. 入れたいフォルダにチェックを付けます (複数可)。決めない場合は「未分類」です。Tick the folders you want (more than one is fine). If you pick none, it goes to "Unsorted".
  3. 新しいフォルダは、「フォルダを追加」から、名前・アイコン・色を決めて作れます。Make a new folder with "Add folder": choose a name, icon and color.

整理して探すSort and find

  1. ツールバーのアイコンから、管理画面かサイドパネルを開きます。Open the manager page or the side panel from the toolbar icon.
  2. 左のフォルダを選び、カード・リスト・グリッドで見ます。Pick a folder on the left and view it as cards, a list or a grid.
  3. 検索、並べ替え、絞り込みで探します。複数選択して、まとめて移動もできます。Search, sort and filter. You can also select several posts and move them at once.

ブックマークを取り込むImport your bookmarks

  1. 設定の「ブックマークの自動取り込み」から始めます (確認の画面で、内容を読んで同意します)。Start from "Import bookmarks automatically…" in Settings (read the confirmation screen and agree).
  2. 速度と、1 回の上限を選びます。一時停止・停止は、いつでもできます。Choose the speed and the limit per run. You can pause or stop at any time.
  3. X が制限や警告を出したときは、自動で止まります。自動スクロールは、X の規約上の「自動化されたアクセス」とみなされる可能性があります。It stops by itself if X shows a limit or a warning. Note that automatic scrolling may be treated as "automated access" under X's terms.
