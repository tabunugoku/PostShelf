仕分けは、ポストを見たその場で済みます。Sort a post right where you read it.

名前・アイコン・色を選べるフォルダFolders with your own name, icon and color

フォルダは自由に作れます。1 つのポストを複数のフォルダに入れることもできます。フォルダは 3 段まで重ねられます。Make as many folders as you like. One post can go into several. Folders can be nested up to three levels.

INSTALL

インストールは手動です。4 ステップで約 3 分かかります。Installing is manual: four steps, about three minutes.

Chrome ウェブストアでは配布していないため、ZIP を取得して自分で読み込みます。PostShelf is not on the Chrome Web Store, so you download a ZIP and load it yourself.

1

ZIP を取得するGet the ZIP

GitHub の Releases から postshelf-1.1.8.zip (最新版) をダウンロードします。Download postshelf-1.1.8.zip (the latest version) from GitHub Releases.

2

展開して置くUnzip it

固定の場所のフォルダに展開します。削除や移動をしない場所にしてください。Unzip it into a folder you will keep. Pick a place where it will not be deleted or moved.

3

デベロッパーモードをオンにするTurn on Developer mode

chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。Open chrome://extensions and turn on "Developer mode" at the top right.

4

読み込むLoad it

「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。Choose "Load unpacked" and select the folder you unzipped.

更新するとき: 先に設定の「データの保存と移行」でエクスポートし、同じフォルダに新しいバージョンを上書きして、「再読み込み」を押します。拡張機能は削除しないでください (保存したデータも消えます)。Updating: first export your data in Settings ("Backup and transfer"), then overwrite the same folder with the new version and press "Reload". Do not remove the extension, or your saved data goes with it.

FAQ

入れる前に気になること。Before you install.

保存したポストは、どこに置かれますか。Where are my saved posts stored?

あなたのパソコンの中だけです。外部のサーバーには送りません (新しいバージョンを確かめる設定をオンにしたときは、GitHub にバージョン番号だけを問い合わせます)。拡張機能を削除すると、保存したデータも消えます。設定のエクスポートで、先に書き出しておけます。Only on your computer. Nothing is sent to an outside server (if you turn on "Check for new versions", PostShelf only asks GitHub for the latest version number). Removing the extension also removes the saved data, so export it from Settings first if you want a copy.

なぜ Chrome ウェブストアにないのですか。Why isn't it on the Chrome Web Store?

いまは、GitHub で ZIP を配布しています。ソースコードと変更履歴をそのまま読めるので、使う権限の中身も自分で確かめられます。ストアへの公開はまだ行っていません。インストールの手順は、上に 4 ステップで書いてあります。For now, the ZIP is distributed on GitHub. You can read the source code and the change history as they are, so you can check for yourself what permissions it uses. It is not published on the Chrome Web Store yet. The four install steps are above.

スマホでも使えますか。Does it work on a phone?

使えません。パソコンの Chrome で動く拡張機能です。No. It is a Chrome extension for computers.

自動取り込みを使うとき、気をつけることはありますか。Is there anything to watch out for with automatic import?

取り込みは任意で、確認の画面で同意してから始まります。速度は抑えてあります。一時停止や停止はいつでもでき、X が制限を出したときは自動で止まります。ただ、自動スクロールは X の規約上の「自動化されたアクセス」とみなされる可能性があるので、使うかどうかはご自身で決めてください。It is optional and starts only after you agree on a confirmation screen. It runs at a gentle pace, can be paused or stopped at any time, and stops by itself if X shows a limit. Automatic scrolling may still be treated as "automated access" under X's terms, so it is your call whether to use it.
