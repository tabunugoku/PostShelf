FEATURES

整理に必要なものを、ひと通り。

見た目は X に近く、操作は迷いません。

自由なフォルダ

名前・アイコン・色を自由に選べます。1 つのポストを、複数のフォルダに入れることもできます。

x.com でそのまま保存

ブックマークボタンの横に、フォルダを選ぶ小さなメニューが出ます。画面を離れずに分類できます。

3 つの表示

X 風のカード、リスト、グリッドを切り替えられます。サイドパネルでも使えます。

探しやすい

本文と投稿者の検索、並べ替え、「画像あり」「動画あり」「リンクあり」の絞り込み、最近 7 日のスマートビュー。

動画と画像を見分けられる

動画には再生ボタンと「動画」の札、複数枚の画像には枚数の札が付きます。

長いポストも全文で

たたまれたポストの全文を読み取り、PostShelf でたたむ・広げるを切り替えられます。本文中のリンクも開けます。

複数アカウント

X のアカウントごとに、フォルダとポストを分けて管理します。

取り込みと書き出し

既存のブックマークを、確認のうえで自動取り込み (任意)。JSON でのエクスポート / インポートにも対応します。

データは端末の中だけ

保存先はブラウザの中だけ。外部への送信も、解析も、アカウント登録もありません。

フォルダの色は 8 色 (と色なし)

アイコンも、どの色でも選べます。

INSTALL

インストールは、4 ステップ (約 3 分)

Chrome ウェブストアでは配布していないため、ZIP を取得して手動で読み込みます。

1

ZIP を取得

GitHub の Releases から postshelf-1.1.0.zip (最新版) をダウンロードします。

2

展開して置く

固定の場所のフォルダに展開します。削除や移動をしない場所にしてください。

3

デベロッパーモード

chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。

4

読み込む

「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。

更新するとき: 先に設定の「データ」からエクスポートで保存してから、同じフォルダに新しい版を上書きし、「再読み込み」を押します。拡張機能は削除しないでください (保存したデータも消えます)。

HOW TO USE

使い方

場面ごとに、手順を示します。

ポストを保存する

  1. x.com で、ブックマークボタンの横にある PostShelf のボタンを押します。
  2. 入れたいフォルダにチェックを付けます (複数可)。決めない場合は「未分類」です。
  3. 新しいフォルダは、「フォルダを追加」から、名前・アイコン・色を決めて作れます。

整理して探す

  1. ツールバーのアイコンから、管理画面かサイドパネルを開きます。
  2. 左のフォルダを選び、カード・リスト・グリッドで見ます。
  3. 検索、並べ替え、絞り込みで探します。複数選択して、まとめて移動もできます。

ブックマークを取り込む

  1. 設定の「ブックマークの自動取り込み」から始めます (確認の画面で、内容を読んで同意します)。
  2. 速度と、1 回の上限を選びます。一時停止・停止は、いつでもできます。
  3. X が制限や警告を出したときは、自動で止まります。自動スクロールは、X の規約上の「自動化されたアクセス」とみなされる可能性があります。
