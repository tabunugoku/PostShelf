PostShelf 画面の改善案 (before / after)

スクリーンショット (docs/screenshots/ とご提示の x.com の画像) を見て、直したほうが良い所を 4 つ選びました。それぞれに評価を付けています。採用するかどうかは、ご判断ください。

1. 保存ポップオーバーの「フォルダを作成」メニュー

ご指摘の 2 点 (アイコンが 2 行になる、アイコンが枠の中央に来ない) を直します。

直す点

  • 「アイコン」「色」のラベルを、並べる列の上に置く。アイコン 8 個が、ちょうど 1 行 (幅いっぱいを 8 等分) に収まる。
  • アイコンのボタンは、中央寄せ (display:grid; place-items:center) にして、アイコンは display:block・line-height:1 の 1 つの箱にする。x.com 側の CSS (button / i の余白や基準線) に引きずられないよう、box-sizing・margin・padding・line-height を明示する。
  • 選択中は、枠線 + 薄い背景。色は、選択中に二重のリングを付ける。
  • 名前・アイコン・色を決めると、プレビュー (作ったあとの見え方) が 1 行で出る。名前が空のときは「作成」が押せない (いまの動作のまま)。

評価 採用を推奨。ご指摘の不具合そのものの修正で、効果が大きい。変更は folderCreateMenu.ts の CSS と DOM の組み立てだけで、保存の動作には触れない。リスクは小さい (プレビューの 1 行は、不要なら外せる)。実機で、X のダーク / ライト / ダーク青の 3 つで確認する。

2. 保存ポップオーバーのフォルダ一覧と下部の操作

チェックボックスが、ブラウザ標準の灰色の四角のままで、X の画面から浮いています。下部の 2 つの操作 (フォルダを追加 / サイドパネルで開く) も、見分けにくい。

直す点

  • チェックボックスを、角の丸い自前のチェックにする (選択中は、アクセントの色で塗り、白いチェックを出す)。選択中の行には、薄い背景を付ける。実際の入力は、input type="checkbox" を残し (キーボードとスクリーンリーダーの操作はそのまま)、見た目だけを appearance:none で変える。
  • 下部の操作を、同じ形のボタンの行 (アイコン + 文) にそろえる。「PostShelf から外す」は、保存済みのときだけ、区切り線の下に、赤い文字で置く (いまは一覧の下に枠線つきのボタンで出る)。
  • この一覧は、管理画面の「フォルダを変更」と、サイドパネルの保存でも共通 (folderPicker.ts) なので、3 か所とも同時に変わる。

評価 採用を推奨。共通部品の 1 か所を直すだけで、3 か所の見た目がそろう。保存の動作は変えない。リスクは、管理画面側 (CSS 変数のテーマ) で、色が合っているかの確認。

直す点 (「絞り込み」を押すと、4 つの条件が開きます。右の after で試せます)

  • フォルダのチップ列をなくし、ドロップダウンに一本化する (「すべて」「未分類」「最近の 7 日」も、ドロップダウンの先頭の区画に入っている)。
  • 絞り込みの 4 つのチップ (画像あり / 動画あり / リンクあり / 投稿者) は、「絞り込み」のボタンの中に畳む。条件を選んだときは、ボタンに件数のバッジを付けて、選択中だと分かるようにする。
  • 上部が 4 段から 2 段になり、ポストの一覧が、約 90px 広くなる。

評価 判断が分かれる。縦の狭さは確実に解消するが、フォルダの切り替えが、ワンタップから 2 タップになる。サイドパネルは「いま開いているポストを保存する」用途が主で、一覧を見る頻度は管理画面より低いはず。私の推奨は、絞り込みだけ畳み、フォルダのチップ列は残す (縦が 2 段減るのではなく 1 段減る) か、フォルダのチップ列も畳むかの二択で、ご判断ください。

直す点 (右の after のスイッチを押すと、キャッシュの詳細が開きます)

  • オン / オフの設定 (連動・キャッシュ・自動取り込みなど) を、右端のスイッチにそろえる。ラジオボタン (どれか 1 つを選ぶ設定) は残す。実際の入力は input type="checkbox" role="switch" にして、キーボードとスクリーンリーダーの操作を保つ。
  • 見出し「設定」の歯車は、文字との間に余白を空ける (いまは、くっついている)。
  • 「画像のキャッシュ」は、オフのとき、詳細 (保存先・容量・画質・いっぱいになったとき・長い注意書き) を畳み、1 行の案内だけにする。オンにしたときに開く。
  • 「初めてオンにするとき、Chrome が許可を求めます」の説明は、スイッチをオンにする前に読めるよう、スイッチの下の短い補足にする。

評価 採用を推奨 (スイッチと余白)。キャッシュを畳むのは、判断が分かれる。画面は短くなるが、オフのままでは、どんな設定があるかが見えなくなる。畳むなら、案内の 1 行に、設定の概要を書いておく。

スクリーンショット (tab-grid-dark.png) で、1 枚目のカードにマウスを乗せると、チェックと 3 つの操作ボタンが、投稿者名 (「Dev Tips @devtips」) の上に重なっています。

  • チェックは、カードの左上の角に、丸いバッジとして出す (選択中だけ塗りつぶし)。ホバー時にだけ出る枠の中のチェックはやめる。

6. 管理画面の上部: お知らせの帯が積み重なる

スクリーンショット (tab-account-menu-dark.png) で、「アカウント未設定のポストがあります」と「取り込めるポストが 12 件あります」の 2 本の帯が、並んで出ています。さらに絞り込みのチップ、複数選択時の操作バーが続き、一覧が始まるまで、縦に 4 段ぶん使います。

  • お知らせの帯は、いちばん大事な 1 本だけを出し、残りは「他に N 件」で開く (押すと、次の帯に切り替わる。優先順は、アカウント未設定 → 取り込み)。

7. アカウントの切り替えメニュー: アイコンだけの操作と、隣り合う削除

スクリーンショット (tab-account-menu-dark.png) で、各行の右端に、矢印 (⇄) とごみ箱のアイコンだけが並んでいます。矢印の意味が分からず、アカウントのデータを削除するごみ箱が、すぐ隣にあります。

  • 行をクリックすれば、そのアカウントの表示に切り替わる (いまの矢印のボタンは、行のクリックに統合)。
  • 「アカウント未設定」の行にだけ、文字の「割り当て…」ボタンを出す。ほかのアカウントでは、割り当ては要らない。

評価 採用を推奨。意味が不明なアイコンをなくし、削除の誤操作の危険も下がる。確認の画面がすでにあるので、動作は変わらない。

小さな改善案 (モックなし)

  • 自動取り込みの停止ボタン: 進捗パネルの「停止」が赤い枠で、データが消えるように見える。実際は「そこまでの分は保存される」ので、色は普通の枠にする。
  • 自動取り込みの確認ダイアログ: 規約の注意 (黄色い枠) を、速度の設定より上に置き、注意 → 設定 → 同意 → 始める、の順にする。
  • ビューア: 見えている画面は問題なし (閉じる・前後・開くボタンが、はっきり見える)。変更は提案しない。
