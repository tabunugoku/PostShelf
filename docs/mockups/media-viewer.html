画像と動画をクリックしたとき (案)

管理画面 (タブ / サイドパネル共通) のポストで、画像・動画をクリックしたときの表示です。左のカードでクリックを試せます。

動画つきのポスト。サムネイルを押すと案内が出ます。

できること・できないこと

できる画像 PostShelf は、画像の URL を保存しています。クリックしたときは、X の画像サーバーにある大きいサイズ (name=orig など) を読み込んで表示します。新しい通信先は増えません (いまのサムネイルも同じサーバーから読んでいます)。
  • 複数枚は ← → で前後、Esc で閉じる
  • 「元のサイズで開く」は新しいタブで画像だけを開く
  • 「X でポストを開く」で元のポストへ
制限あり動画 動画の実体 (再生用のファイル) は、X の画面から正規の方法で取り出せません。保存できるのはサムネイルだけです。そのため、動画はクリックすると「X で再生」へ案内します (X の非公開 API を呼ばない方針は変えません)。
  • サムネイルは、新しいポストから保存します (古い保存分は動画アイコンの枠のみ)
  • 元のポストが削除されると、画像が表示できなくなることがあります (右の「読み込めない」の表示)

設定: 画像のキャッシュ (案)

保存した画像を PostShelf 側にも残す機能です。初期値はオフ。保存先と最大容量を選べます。設定画面の「データ」の近くに置きます。

ポストを保存するときに、画像を端末に残します。X 側で消えても見られます。動画はサムネイルだけです。

保存先
D:\PostShelf-images
許可が必要です Chrome を再起動すると、フォルダへのアクセス許可が外れることがあります。
フォルダの選択はタブ版の管理画面で行います (サイドパネルでは選べません)。
最大容量
使用中 412 MB / 1 GB (画像 1,284 枚)
画質
容量がいっぱいになったら
まとめてキャッシュは、1 枚ずつ順に読み込みます (進捗を表示。いつでも止められます)。ポストを削除すると、そのポストの画像も消えます。
初めてオンにするとき Chrome が「pbs.twimg.com (X の画像サーバー) へのアクセス」の許可を求めます。許可は、この機能をオンにしたときだけ求めます (拡張機能の更新だけで求められることはありません)。
ルール
  • 保存した画像は、この PC の中だけに置きます。外部へ送りません
  • JSON のエクスポートに画像は入りません (URL のみ)
  • 表示するとき、キャッシュがあればそれを使い、無いときだけ X の画像サーバーから読みます
  • 最大容量を下げたときは、すぐに古いものから整理します (確認の画面を出します)

決めたいこと

この設定の見た目と項目でよいですか？ よければ、モックアップのままクラウドに渡します。足したい項目 (例: 画像をまとめて書き出す) や、いらない項目があれば教えてください。
