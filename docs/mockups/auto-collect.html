ブックマークの自動取り込み (画面案)

x.com の「履歴 → ブックマーク」を自動でスクロールして取り込む機能です。実行中の画面 (左) と、開始前の確認 (右) を並べています。

実行中に出す内容
  • 取り込んだ件数、すでにあったためスキップした件数、読み込み済みの範囲 (いちばん古い投稿の日付)
  • 全体の件数は X が教えないので、割合は出さず「進行中」のバーにする
  • 一時停止と停止をいつでも押せる。停止しても、そこまでの分は保存済み
  • 別のタブへ切り替えたとき、アカウントが変わったとき、X がエラーや制限を表示したときは、自動で一時停止
  • 速度は「ゆっくり」(1 回のスクロールごとに 2〜4 秒待つ。既定) か「標準」(1〜2.5 秒)
並び順を X と同じにする仕組み X のブックマークは「新しく追加した順」で、下へスクロールするほど古くなります。取り込むときは、画面に出てきた順番をそのまま記録し、PostShelf の「保存が新しい順」でも同じ順に並べます。一時停止から再開したとき、すでに取り込んだ投稿はスキップし、新しく見つかった投稿は、X の並びで直前にあった投稿のすぐ後ろに入れます。

2. 開始前の確認と案内 (管理画面)

X のブックマークを取り込みますか？

@tabunugoku_dev で、初めて PostShelf を使います。x.com の「履歴 → ブックマーク」を開き、画面を自動でスクロールしながら取り込みます。

表示するのは、初めて入れたとき、または、初めて見るアカウントに切り替えたときです。自動では始まりません。「始める」を押したときだけ動きます。設定の「データ」からいつでも手動で実行できます。

自動スクロールは、X の規約が禁じる「自動化されたアクセス」とみなされる可能性があります。アカウントの制限などが起きても、PostShelf は責任を負えません。取り込みは、あなた自身の判断で、あなたのアカウントに対してだけ行ってください。
