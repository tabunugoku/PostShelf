設定画面の整理 (モック)

3 つの指摘 (説明が横に長い / 「データ」欄の寄せ集め / GitHub ボタンの位置) への案です。

1. 「X のブックマークと連動する」の説明を、短い行に分ける

before
X のブックマークと連動する
フォルダに保存したとき X 標準のブックマークも付け、すべてのフォルダから外したとき X 側のブックマークも外します。PostShelf が画面上のブックマークボタンを押すのは、操作したポスト 1 件につき 1 回だけです。初期値はオフです。
after
X のブックマークと連動する
  • フォルダに保存したとき、X 標準のブックマークも付けます。
  • すべてのフォルダから外したとき、X 側のブックマークも外します。
  • ブックマークボタンを押すのは、操作したポスト 1 件につき 1 回だけです。
初期値はオフです。
説明の文は、意味を変えずに 3 つの短い文に分け、箇条書きにします。ほかの設定の説明も、同じ長さの目安 (1 行 40 字前後、横幅は最大 40 文字分) にそろえ、画面を広げても行が間延びしないようにします。

「データ」は、エクスポート / インポートだけにします。自動取り込みは独立した欄、バージョンと更新の手順は「PostShelf について」の欄に分けます。ほかの欄 (X の画面構造、設定の初期化、危険な操作) は、いまのままです。欄の並びは、「連動 → ボタンの動作 → 画像のキャッシュ → データの保存と移行 → 自動取り込み → X の画面構造 → PostShelf について → 設定の初期化 → 危険な操作」にします。

提案: 左のメニューの一番下、「設定」の下に、小さな丸いボタン「GitHub」(ロゴ + 外部リンクの印) を置きます。どの画面にいても見えます。左のメニューが狭いとき (幅が足りないとき) は、ロゴだけにして、文字は読み上げ用の名前 (`aria-label`) に残します。サイドパネルには置きません。設定の中の GitHub ボタンは外します。
確認: 矢印の先を、「左のメニューの『設定』の下」と読みました。違っていれば教えてください。
