# 実機確認チェックリスト (ユーザーが後で実施)

クラウド環境では x.com を実ブラウザで確認できないため、以下は実機で確認する。

## M2 content script
- [ ] `npm run build` 後、`chrome://extensions` で `dist/` を読み込める
- [ ] タイムラインの各ポストのブックマークボタン横に「▾」が出る
- [ ] 「▾」でフォルダ選択ポップオーバーが開き、Esc / 外クリックで閉じる
- [ ] チェックで保存、外すと解除 (全部外すとブックマークが消える)
- [ ] 「新しいフォルダ」から作成すると、そのフォルダにチェックが付く
- [ ] 個別ポスト画面でも動く
- [ ] 無限スクロールで増えたポストにも「▾」が付き、二重にならない
- [ ] 保存されたスナップショット (本文/投稿者/アバター/画像/日時/URL) が正しい

## M3 manager / popup
- [ ] popup に件数・フォルダ数が出て、「管理画面を開く」で manager が新規タブに開く
- [ ] manager: フォルダ一覧、件数、「すべて」に編集ボタンが出ない
- [ ] 編集パネルで名前/アイコン変更、フォルダアイコンのときだけ色が選べる (他は無効表示)
- [ ] ポスト表示 / リスト表示の切替、検索、並べ替え
- [ ] フォルダ削除 (ポストは「すべて」に残る)
- [ ] Tabler Icons が表示される (CSP でフォントがブロックされない)
