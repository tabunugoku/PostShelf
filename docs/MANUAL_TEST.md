- ピッカーの開閉の後のフォーカスは、セレクタに id を埋め込まず、行を走査して探す(jsdom に CSS.escape が無く、既存のテストが壊れるため。引用符を含む id でも壊れない)。
- 取得の途中で拡張機能を更新・再読み込みすると、記録が消えるので、裏のタブは閉じずに残る (旧版の storage.local では閉じていた)。無関係のタブを閉じる不具合を避けるための、受け入れた制約。
- 保存データの形、権限、外部通信、_locales、バージョンは変更しない。
