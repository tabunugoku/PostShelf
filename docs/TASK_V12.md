## A. `static/_locales/ja/messages.json`
| キー | 修正後 |
|---|---|
| `cacheCleanupNeeded` | 削除したポストのうち、画像の削除が済んでいないものがあります。保存先の許可を確認してから、「今すぐ整理」を押してください。 |
| `cacheQualityLarge` | 標準（1 枚あたりの目安 0.2〜0.5 MB。表示には十分） |
| `cacheQualityOrig` | 元のサイズ（1 枚あたりの目安 1〜5 MB。容量が早く減ります） |
| `cacheBulkHelp` | まとめてキャッシュは、1 枚ずつ順に読み込みます。進捗を表示し、いつでも止められます。止めても、次に押すと続きから始まります。ポストを削除すると、そのポストの画像も消えます。 |

理由 (コメントや commit に残さなくてよい):
- `cacheCleanupNeeded`: 「ポストを削除したときに、画像の削除が済んでいないものがあります」は、「もの」が何を指すか読み取りにくい。削除したポストのうち、画像の削除が済んでいないものを指す
- `cacheQuality*`: 容量の数値は見積もりで、実際は画像によって変わる。「目安」を入れる
- `cacheBulkHelp`: 括弧の中に文 (「進捗を表示。いつでも止められます」) が入っていたので、括弧をやめて文にする
