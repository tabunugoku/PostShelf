# TASK v17: v15 で増えた日本語文言の修正

v16 が終わったあとに実施する。日本語 (`_locales/ja/messages.json`) の文言を直し、他の 7 言語にも同じ意味の変更を反映する。コードの動作は変えない。

## 直す文言
キー名は目安。`messages.json` で、現在の文言から探して直す。

| 場所 (キー) | いまの文言 | 直した文言 |
|---|---|---|
| `acBtnAutoTitle` | ブックマークのタブを自動でスクロールして、すべて取り込みます。確認は管理画面で行います | ブックマークのタブを自動でスクロールして取り込みます。1 回の上限は設定で変えられます |
| 「自動で停止しました」の文言 (`acPanelLimit` 付近) | 自動で停止しました | 自動で止めました |
| 「取り込みを終了しました」の文言 (`acPanelStopped` 付近) | 取り込みを終了しました | 取り込みを終えました |
| `acReasonLimit` | X が制限を表示した可能性があります | X が制限を表示したかもしれません |
| 「そこまでの分は保存済みです」の文言 | そこまでの分は保存済みです | ここまでの分は、すでに取り込んであります |
| `acSubRunningDate` | $SPEED$。$DATE$ ごろの投稿を読み込み中 | $SPEED$で読み込み中。いま $DATE$ ごろの投稿です |

直す理由は次のとおり。

- 「すべて取り込みます」は、1 回の上限 (既定 300 件) と食い違う。「確認は管理画面で行います」は、何の確認か分からない。上限があると分かる文にする。
- 「停止」「終了」と「止めました」が混ざっていた。画面全体の「止める」「終える」にそろえる。
- 「そこまで」は、どこまでを指すか曖昧だった。「ここまでの分」とし、状態は「取り込んである」と書く。
- 日付の文は、「読み込み中」の対象が日付だけに読めた。いまの位置が分かる形にする。

## 守ること
- `$SPEED$`、`$DATE$` などのプレースホルダーの名前と数は、変えない。
- 直した文言を使っているテスト (文字列を直接比べているもの) があれば、新しい文言に合わせる。
- 他の 7 言語 (en, zh_CN, zh_TW, ko, es, pt_BR, fr) は、同じ意味になるよう直す。特に次の 2 点。
  - 1 回の上限があることが分かる (「すべて」を意味する語を使わない)。
  - 「確認は管理画面で行う」にあたる文を入れない。
- キーを増やしたり、減らしたりしない。`npm run release:check` のキーの突き合わせが通ること。

## 実機で確かめる項目 (`docs/MANUAL_TEST.md` に足す)
- 速度の目安 (「目安: 1 分に約 20〜40 件」「約 40〜80 件」) は、実機で測った値ではない。実際に取り込んで、1 分あたりの件数を測り、数字が大きくずれていれば直す。測るまでは、いまの数字のままにしておく。
- 直した文言が、取り込み中、一時停止中、自動停止後の各画面で、はみ出さずに表示される。
