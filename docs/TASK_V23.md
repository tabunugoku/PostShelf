# TASK v23: 設定画面に GitHub のリンクを置く

v22 が終わったあとに実施する。見た目の追加だけを行う。保存データの形と動作は変えない。

基準は `docs/mockups/github-link.html` の案 B (ユーザーが決めた)。モックは見た目の案であり、ピクセルの指定ではない。配色と余白は、設定画面の既存のスタイルに合わせる。

## 変えること
1. 設定画面の一番下の、バージョン表示 (`src/manager/Settings.tsx` の `version-info`) の下に、GitHub へのリンクをボタンの形で置く。
   - 見た目: 枠のある丸いボタン。左に GitHub のロゴ、ラベル「GitHub で見る」、右に小さな「外部リンク」のアイコン。
   - リンク先: `https://github.com/tabunugoku/PostShelf`。URL は定数 1 か所にまとめる (例: `src/shared/links.ts`)。
   - `<a>` 要素で、`target="_blank"` と `rel="noopener noreferrer"` を付ける。クリックしても、拡張自身は外部通信をしない (ブラウザが新しいタブで開くだけ)。
2. GitHub のロゴ (Tabler の `brand-github`) と、外部リンクのアイコン (`external-link`) を、ほかのアイコンと同じ手順でローカルに同梱する。CDN は使わない。すでに同梱されているものは再利用する。
3. ラベルと、読み上げ用の文言を、8 言語すべてに入れる。`aria-label` は、新しいタブで開くことが分かる文言にする (例:「GitHub で見る (新しいタブで開きます)」)。`npm run release:check` のキーの突き合わせが通ること。

## 守ること
- 必須の権限は増やさない。ホストの権限も増やさない。外部通信のコードは足さない。
- キーボード操作 (Tab で届き、Enter で開く) と、フォーカスの見た目を保つ。ライト / ダークのどちらでも読める。
- 既存のバージョン表示の文言と、診断情報のコピーなどの設定の項目は、変えない。
- リポジトリは現在**非公開**。公開するまで、他の人にはリンクが開けない (404)。この点は、`docs/PUBLISH.md` の公開前の確認項目に 1 行足す (「GitHub のリポジトリを公開にしてから配る」)。
