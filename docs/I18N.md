# 多言語対応 (i18n)

`chrome.i18n` を使用。辞書は `static/_locales/<lang>/messages.json`、コードからは `t(key, ...subs)` (`src/shared/strings.ts`) で参照する。`default_locale` は `en`。

## 対応言語
ja, en, zh_CN, zh_TW, ko, es, pt_BR, fr

## ⚠ ネイティブ校正が必要
**en 以外の翻訳 (ja を含む) は AI による翻訳で、ネイティブ話者の校正を受けていません。** 公開前に各言語の話者によるレビューを推奨します。特に確認したい点:
- 「ポスト / post」(X の呼称は言語・時期で異なる: 例 ja は「ポスト」、zh は「帖子/貼文」、ko は「게시물」)
- 組み込みフォルダ名「すべて / All」「未分類 / Unsorted」の語感
- 連動モードの説明文 (`syncNativeDesc`) の自然さ
- ボタン文言の長さ (es, fr, pt_BR は長くなりがち。レイアウトは固定幅を避けているが実機で確認する)

## 言語を追加する手順
1. `static/_locales/<lang>/messages.json` を作る。ディレクトリ名は [Chrome の対応ロケール](https://developer.chrome.com/docs/extensions/reference/api/i18n#locales) (`pt_BR`, `zh_CN` のようにアンダースコア)
2. キー集合は `en` と完全一致させる。`placeholders` (`importDone`, `collectDone` の `$COUNT$`) は en と同じ定義を保ち、メッセージ内の `$COUNT$` の位置だけ語順に合わせて動かす
3. `test/i18n.test.ts` の「ships the expected languages」の期待配列に追加する (キー一致・プレースホルダのテストは `_locales` 配下を自動で全言語検証する)
4. `npm test` / `npm run typecheck` / `npm run build`
5. Chrome の表示言語を切り替えて実機確認 (`docs/MANUAL_TEST.md`)

日付は `Intl.DateTimeFormat(chrome.i18n.getUILanguage())` なので、辞書への追加は不要。

## 今後の課題
- 第 2 弾: de (ドイツ語)、ru (ロシア語)
- 右から左の言語 (ar, he): `dir="rtl"` と CSS の論理プロパティ (`margin-inline-*` など) への移行が必要。今回は対象外
- 複数形 (「N 件」等): 現在の辞書は数に依存しない言い回しにしている。ru など複数形が複雑な言語を足すときは `chrome.i18n` が複数形をサポートしないため、`Intl.PluralRules` で自前処理が必要
- ネイティブ校正の反映
