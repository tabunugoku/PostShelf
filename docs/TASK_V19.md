# TASK v19: 画面の見た目の改善

v18 が終わったあとに実施する。見た目 (CSS と、DOM の組み立て) の改善だけを行う。保存データの形、保存と取り込みの動作は変えない。

基準は `docs/mockups/ui-polish.html` (before / after のモックアップ)。ユーザーが採用を決めたのは、モックの 1〜7 と「小さな改善案」。モックの 8 (ツールバーのポップアップ) は保留なので、**今回は触らない**。

モックは見た目の案であり、ピクセルの指定ではない。実際の配色・余白・フォントは、既存の画面 (X のテーマに合わせた x.com の部品、アプリ側の CSS 変数) に合わせる。

## 1. 「フォルダを作成」メニュー (v19-A)
ご指摘の不具合は、アイコンが 2 行になることと、アイコンがボタンの中央に来ないこと。

- 「アイコン」「色」のラベルを、並べる列の上に置く (いまは、ラベルが列の左にあり、幅が足りなくて折り返す)。アイコン 8 個は、幅いっぱいを 8 等分した 1 行 (`display:grid; grid-template-columns:repeat(8,1fr)`) にする。
- アイコンのボタンは、`display:grid; place-items:center`、正方形 (`aspect-ratio:1`)、`padding:0` にする。中のアイコンは `display:block; line-height:1` の 1 つの箱にする。
- x.com 側の CSS が、ボタンと `i` の余白・基準線・フォントの扱いに影響している可能性が高い。そのため、`box-sizing`・`margin`・`padding`・`line-height`・`font`・`appearance` を、このメニューの部品すべてに明示する。
- 選択中のアイコンは、枠線 (アクセント色) と薄い背景。選択中の色は、二重のリング。
- 名前・アイコン・色のプレビューを 1 行で出す (名前が空のときは薄くして「フォルダ名」を出す)。「作成」が空のときに押せない動作は、いまのまま。
- 管理画面の「フォルダを変更」と、サイドパネルの保存でも同じメニューを使っているので、3 か所とも同時に直る。

## 2. フォルダ一覧と下部の操作 (v19-A)
- チェックボックスを、角の丸い自前のチェック (選択中は、アクセント色で塗り、白いチェック) にする。実際の入力は `input type="checkbox"` を残し (キーボードとスクリーンリーダーの操作はそのまま)、`appearance:none` で見た目だけを変える。選択中の行には、薄い背景を付ける。
- 下部の操作を、同じ形のボタン (アイコン + 文) に、そろえる。順序は、「フォルダを追加」、「サイドパネルで開く」、区切り線、「PostShelf から外す」。
- 「PostShelf から外す」は、保存済みのときだけ出す。赤い文字で、ごみ箱のアイコンを付ける。
- 一覧は共通部品 (`folderPicker.ts`) なので、x.com、管理画面、サイドパネルの 3 か所が同時に変わる。管理画面では、アプリ側の CSS 変数 (テーマ) で、色が合っていることを確かめる。

## 3. サイドパネルの上部 (v19-B)
- フォルダのチップ列をなくし、ドロップダウンに一本化する。ドロップダウンの先頭の区画に、「すべて」「未分類」「最近の 7 日」を入れる (すでに入っている場合は、そのまま)。
- 絞り込みの 4 つのチップ (画像あり / 動画あり / リンクあり / 投稿者) は、「絞り込み」ボタンに畳む。押すと、同じ 4 つが開く。条件を選んでいるあいだは、ボタンに件数のバッジを出す。
- 上部は、「[フォルダ ⌄] [検索] [管理画面を開く]」と、「[並べ替え ⌄] [絞り込み] …… [表示切り替え]」の 2 段にする。
- 絞り込みの条件の選び方・保存のされ方 (いまの状態の持ち方) は変えない。

## 4. 設定画面 (v19-C)
- オン / オフの設定 (X のブックマークとの連動、画像のキャッシュ、自動取り込みを使う、ほか) を、右端のスイッチにそろえる。実際の入力は `input type="checkbox" role="switch"`。ラジオボタン (どれか 1 つを選ぶ設定) は、そのまま残す。
- 見出し「設定」の歯車のアイコンと文字の間に、余白を空ける。
- 「画像のキャッシュ」がオフのときは、詳細 (保存先・最大容量・画質・いっぱいになったとき・まとめてキャッシュ・長い注意書き) を畳み、「オンにすると、保存先・容量・画質を選べます」の 1 行だけにする。オンにしたら、詳細を開く。
- 「初めてオンにするとき、Chrome が許可を求めます」の説明は、スイッチの下の短い補足として、オンにする前に読める位置に出しておく。畳んだときも、この補足は残す。
- キャッシュのオン / オフの動作 (許可の求め方、保存先の切り替えの確認) は変えない。

## 5. グリッド表示のホバー (v19-B)
- ホバーで出る、枠の中のチェックと 3 つの操作ボタンが、投稿者名と重なる。直す。
- チェックは、カードの左上の角に、丸いバッジとして出す (選択中は塗りつぶし、選択中でないときは、ホバーとフォーカスのときだけ出す)。
- 操作ボタン (フォルダ変更 / X で開く / 削除) は、カードの下の行の右端 (フォルダのチップと同じ行) に置く。ホバーとキーボードのフォーカスで出す。
- 投稿者名と本文には、重ならない。ポスト表示・リスト表示は、重ならないので、変えない。

## 6. 管理画面の上部 (v19-B)
- お知らせの帯は、いちばん大事な 1 本だけを出す。残りは、「他に N 件」を押して、次の帯に切り替える。優先順は、アカウント未設定の割り当て → ブックマークの取り込みの案内。
  - 自動取り込みの進捗の表示 (動いているときの状態) は、お知らせではなく状態の表示なので、この統合の対象にしない。いまのまま、常に出す。
  - 帯を閉じる (×) 動作と、閉じた記録の持ち方は、変えない。
- 複数選択のバーは、絞り込みの行の右端のボタン「N 件選択中 ⌄」に置き換える。押すと、「フォルダに追加」「フォルダから外す」「削除」「選択解除」が開く。何も選んでいないときは、このボタンを出さない。
  - 一覧が、選択のたびに下へずれないこと。
  - 削除の確認と、取り消しの通知は、いまのまま。
  - すでにあるキーボード操作 (Esc で選択解除、など) は、変えない。

## 7. アカウントの切り替えメニュー (v19-C)
- 行をクリックしたら、そのアカウントの表示に切り替える (いまの矢印 ⇄ のボタンは、行のクリックに統合して、なくす)。
- 「アカウント未設定」の行にだけ、文字のボタン「割り当て…」を出す。
- ごみ箱は、各行の「…」のメニューの中の「このアカウントのデータを削除…」に入れる。確認の画面 (いまのもの) を経て削除する動作は変えない。
- 文言は、既存のキーを再利用する。足りないものだけ、新しいキーを 8 言語に足す。

## 小さな改善案 (v19-D)
- 自動取り込みの進捗パネルの「停止」を、赤い枠から、普通の枠 (ほかのボタンと同じ) に変える。「停止」しても、そこまでの分は保存される。赤は、データが消える操作 (削除など) だけに使う。
- 自動取り込みの確認ダイアログの順を、「説明 → 規約の注意 (黄色い枠) → 速度と 1 回の上限 → 並び順の図 → 同意 → 始める」にする。
- ビューアは、変えない。

## 守ること
- 保存データの形、保存の動作、取り込みの動作は変えない。見た目と DOM の組み立てだけ。
- 必須の権限は増やさない。外部通信もしない。
- キーボード操作と、スクリーンリーダー向けの属性 (`aria-*`、`role`) を保つ。スイッチとチェックは、実際の `input` を残す。
- 色は、ライト / ダーク (アプリ側)、X のライト / ダーク / ダーク青 (x.com 側) のすべてで読める。
- 新しい文言は、8 言語すべてに入れる。`npm run release:check` のキーの突き合わせが通ること。
- 文字列を直接比べているテストは、新しい見た目に合わせて直す。

## テスト
- 1: 作成メニューの、アイコンが 1 行に並ぶ (8 個のボタンが同じ縦位置にある)。アイコンがボタンの中央にある (DOM の構造とスタイルで確かめる)。プレビューが、名前・アイコン・色に追従する。
- 2: チェックは、実際の `input type="checkbox"` のまま。選択中の見た目の印 (クラスまたは属性) が付く。「PostShelf から外す」は、保存済みのときだけ出る。
- 3: サイドパネルに、フォルダのチップ列がない。「絞り込み」を押すと、4 つの条件が開き、選んだ数のバッジが出る。
- 4: スイッチが `role="switch"` で、キーボード (スペース) で切り替わる。キャッシュがオフのときは詳細が畳まれ、オンで開く。
- 5: グリッドのカードで、操作ボタンの行が、投稿者名の行と別の位置にある (重ならない)。
- 6: お知らせが 2 つあるとき、帯は 1 本で、「他に 1 件」で切り替わる。選択すると「N 件選択中」のボタンが出て、メニューから 4 つの操作ができる。選択のたびに、一覧の位置がずれない。
- 7: 行のクリックで切り替わる。ごみ箱は、「…」のメニューの中にあり、確認の画面を経て削除される。
- 小: 「停止」のボタンに、赤の指定がない。ダイアログの順が、決めたとおり。
