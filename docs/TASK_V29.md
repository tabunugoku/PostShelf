## A. サイドパネルの「いま開いているポスト」 (`src/manager/SaveCurrent.tsx`、`src/manager/App.tsx`、`static/manager.css`)

### 現状
- サイドパネル下部の固定欄 (`.pfoot`) に、「いま開いているポストを保存…」ボタンがある。押すと、そのタブの content script から `requestSnapshot` でスナップショットを取り、フォルダ選択のドロップダウンを開く。保存は 3 手 (ボタン → メニュー → チェック)。

### 直し方
- `SaveCurrent` を、パネルの**上部**に固定する「いま開いているポスト」の枠にする (`.phead` の下。一覧のスクロールに隠れない)。x.com の `/status/` のポストを開いているあいだだけ出す。それ以外のタブでは出さない (いまの `watchActivePost` の条件のまま)。
- 枠の中身:
  1. 見出し「いま開いているポスト」と、削除のアイコンボタン (右端、`ti-trash`、赤、`aria-label` / `title` は v28 の「PostShelf の保存を削除」と同じ文言)。保存済みのときだけ出す。押したら、確認なしで `removeBookmark` を実行する。
  2. ポストの投稿者と本文の抜粋 (1〜2 行で切る)。スナップショットは、タブが変わったときと、ポストが変わったときに `requestSnapshot` で取る (取れなければ、いまと同じ `saveCurrentFail` を枠の中に出す)。
  3. フォルダのチップ。先頭に、設定の `recentFolderIds` (v28 で追加) のフォルダを並べ、足りなければフォルダの並び順で補い、合計 4 つまで。残りは、チップ「他の N つ ⌄」で、既存のフォルダ選択 (`FolderPickerHost`) を開く。「未分類」はチップに出さない (チェックを全部外すと「未分類」になる、いまの規則のまま)。
  4. チップを押すと、その場で保存する (チェックの切り替え。保存のしかたは、いまのドロップダウンの `onChange` と同じ: `setBookmarkFolders`、初めての保存のときだけ `requestCache` / `requestFullText`、`requestNativeSync`、`props.onSaved()`)。結果は、チップの下に 1 行で出す (「✓ 保存しました (フォルダ名)」)。選ばれているチップには ✓ を付ける。
- `blockedReason` (アカウントを判定できない / 表示中のアカウントが違う) のときは、チップを出さず、いまと同じ警告を枠の中に出す。
- 下部の `.pfoot` と、文言 `saveCurrentHint` の表示は、なくす。使われなくなった文言キーは、他で使っていなければ削除せず残してよい。
- 新しい文言 (8 言語): `activePostTitle` (いま開いているポスト)、`activeSaved` (保存しました ($FOLDER$))、`activeMoreFolders` (他の $COUNT$ つ)。

## C. 未分類の「仕分けモード」 (新規 `src/manager/Triage.tsx`、`src/manager/App.tsx`、`static/manager.css`)

### 目的
自動取り込みで未分類が数百件たまっても、1 件 2〜3 秒で仕分けられるようにする。AI は使わない。

### 入口
- 管理画面 (タブ版) の「未分類」の表示で、件数が 1 以上のとき、見出しの行に「仕分けモード」ボタンを出す。サイドパネル版 (`compact`) では出さない (狭いので、この版では対象外)。
- URL のハッシュ `#triage` で、管理画面を開き、「未分類」を選んで仕分けモードを始める (v28 で足した `#inbox` と同じ扱い。読み取ったら `history.replaceState` で消す)。未分類が 0 件なら、仕分けモードは始めず、「未分類」の表示だけを開く。

### 動き
- 始めた時点の未分類を、現在の並び順 (`sort`) で固定した列 (キュー) にする。途中で保存データが変わっても (`onDataChanged`)、キューの並びは変えない (件数が減って見えるだけで、画面が飛ばないようにする)。キュー内のポストが削除されたら、飛ばす。
- 画面は、管理画面の上に重ねるダイアログ (`role="dialog"`、`aria-modal`、タイトルは「仕分けモード」)。上に進み具合 (「7 / 24」とバー)、中央に 1 件を大きく (投稿者、日時、本文 = `PostText`、画像があれば 1 枚目のサムネイル)、下にフォルダのボタンを並べる。
- フォルダのボタン: ユーザーのフォルダを並び順で先頭の 9 つまで、番号 1〜9 を付けて出す。10 以上あるときは、「他のフォルダ ⌄」で既存の `FolderPickerHost` を開く。「N」キーで「新しいフォルダ」の作成 (既存の作成メニューを使う)。ボタンは 1 行・nowrap。
- 操作:
  - 数字キー (または押す): そのフォルダを追加して、**次のポストへ進む** (`addToFolders([id], [folderId])`。「未分類」は、フォルダを足すと外れる、いまの規則)。
  - Shift + 数字キー (または Shift + 押す): 追加して、**同じポストに留まる** (複数のフォルダに入れたいとき)。
  - → キー、または「あとで」: 何もしないで次へ。← キー、または「戻る」: 1 つ前へ戻る (戻った先では、入っているフォルダのボタンに ✓ が付き、押すと切り替わる)。
  - Esc: 終わる。
- フォルダを足したポストは「仕分け済み」として数える。キューの最後まで進んだら、終了の画面「仕分けが終わりました」と「N 件を仕分けました」を出し、「閉じる」ボタンだけにする。
- キーボード: ダイアログの中だけでキーを受ける (`keydown` はダイアログの要素に付ける。`window` には付けない)。フォーカスはダイアログに閉じ込め、閉じたら始めたボタンへ戻す。入力欄 (新しいフォルダの名前など) にフォーカスがあるあいだは、数字キーを奪わない。
- 保存データの形は変えない。画像のキャッシュ・全文の取得は、仕分けでは要求しない (すでに保存済みのポストなので)。
