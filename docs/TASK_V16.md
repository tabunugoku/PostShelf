# TASK v16: 保存ポップオーバーのフォルダ追加をボタンからのメニューにする

v15 が終わったあとに実施する。v15 で `createFolderPicker` (`src/shared/folderPicker.ts`) に「未分類」の行を足している。その続きの作業になる。

## 背景
x.com の保存ポップオーバーの下部に、常に「フォルダ名」の入力欄と「追加」ボタンが出ている。フォルダを新しく作るのは、保存のたびに行う操作ではない。常時出しておく必要はなく、ポップオーバーが縦に長くなる。

## 変更内容
1. 「フォルダ名」の入力欄と「追加」ボタンを、ポップオーバーから取り除く。
2. 代わりに「フォルダを追加」ボタンを 1 つ置く (アイコン `ti-folder-plus`、ラベルは `t('addFolder')`。既存の文言があれば再利用する)。位置は、フォルダ一覧のすぐ下、「サイドパネルで開く」の上。
3. ボタンを押すと、同じポップオーバーの中に「フォルダを作成」のメニューが開く。一覧とは切り替えて表示する (一覧は隠し、「← 戻る」で一覧に戻る)。メニューには次を置く。
   - フォルダ名の入力欄 (開いた直後にフォーカスする。空のときは「作成」を押せない)
   - アイコンの選択 (管理画面の編集パネルと同じ `ICONS`。初期は `FOLDER_ICON`)
   - 色の選択 (同じ `COLORS`。初期は色なし)
   - 「作成」と「キャンセル」
4. 「作成」を押したら、フォルダを作る。作ったフォルダは、そのポストの保存先として、チェックを入れた状態で一覧に戻る。このとき他に選んでいるフォルダと「未分類」の排他は、v15 の規則に従う (未分類が選ばれていたら、未分類を外して、新しいフォルダを選ぶ)。
5. 「キャンセル」と「← 戻る」は、何も作らずに一覧へ戻る。入力した内容は捨てる。
6. Escape キーは、メニューが開いているときはメニューだけを閉じる (ポップオーバー全体は閉じない)。
7. 同名のフォルダがすでにあるとき、メニュー内にエラー文を出して作らない (管理画面の既存の判定と同じ規則にそろえる)。

## 実装の方針
- アイコンと色の選択部分は、`src/manager/FolderEdit.tsx` の中身をそのまま複製せず、DOM 版 (`src/shared/` に置く小さな関数) を作って共有できるか検討する。manager は Preact、ポップオーバーは素の DOM なので、共有できない場合は、ポップオーバー側に DOM で実装してよい。その場合も、選択肢 (`ICONS`、`COLORS`) は `models.ts` のものを使う。
- サイドパネルの `SaveCurrent.tsx` と、管理画面の「フォルダを変更」でフォルダ追加の入力が同じ形で出ている場合は、同じ方針に変える。出ていなければ、触らない。
- 新しい権限は足さない。外部通信もしない。
- スタイルは、既存のポップオーバー (ダーク / ライトの両方、`theme.ts`) に合わせる。

## 文言 (8 言語すべて)
新しく足すキーは、`_locales/*/messages.json` の 8 言語すべてに入れる (ja, en, zh_CN, zh_TW, ko, es, pt_BR, fr)。キーの数がそろっていることは `npm run release:check` が確かめる。
- フォルダを追加 / Add folder
- フォルダを作成 / Create folder
- 作成 / Create
- 戻る / Back
- 同名のフォルダがあります / A folder with this name already exists

既存のキー (`cancel` など) があれば、新しく作らず再利用する。

## テスト
- ポップオーバーに、名前の入力欄と「追加」ボタンが最初から出ていない。
- 「フォルダを追加」ボタンを押すと、メニューが開き、名前の入力欄にフォーカスがある。
- 名前が空のときは「作成」が押せない。
- 名前・アイコン・色を指定して「作成」を押すと、その内容でフォルダが作られ、一覧に戻り、そのフォルダにチェックが入っている。
- 「未分類」にチェックが入っている状態で作成すると、未分類が外れ、新しいフォルダだけにチェックが入る。
- 「キャンセル」と「← 戻る」では、フォルダが作られない。
- 同名のフォルダがあるときは、エラー文が出て、作られない。
- Escape でメニューだけが閉じ、ポップオーバーは開いたまま。
- フォルダがまだ 1 つもない状態でも、「未分類」の行と「フォルダを追加」ボタンが出る。
