# よくある質問 (FAQ)

## PostShelf のデータはどこに保存されますか？
PostShelf は **デスクトップ版 Chrome の拡張機能** で、データ (フォルダ・保存したポスト) はその端末のブラウザ内 (`chrome.storage.local`) にだけ保存されます。外部サーバーには一切送信しません。

## スマホの X アプリでブックマークしたポストは PostShelf に入りますか？
**自動では入りません。**
- X のスマホアプリでブックマークしたものは、X のサーバー側に保存されるだけです。
- 拡張機能はスマホのアプリには入れられないため、PostShelf はスマホでの操作を知ることができません。

## スマホでブックマークした分を PostShelf に入れるには？
デスクトップの Chrome で取り込みます。

1. PostShelf を入れた Chrome で x.com にログインし、`https://x.com/i/bookmarks` を開く
2. 取り込みたいポストが画面に出るまでスクロールする (自動スクロールはしません。自分でスクロールしてください)
3. 画面右下の取り込みボタン (「未取り込み N 件」) を押す
4. 取り込まれたポストは「未分類」フォルダに入ります。manager で整理してください (すでに取り込み済みのポストは重複しません)

ボタンの表示:
- **未取り込み N 件**: 画面に出ているポストのうち、PostShelf にまだ保存されていない件数
- **すべて取り込み済み**: 画面に出ているポストはすべて保存済み

※ PostShelf が読むのは、表示中の画面の DOM だけです。X の非公開 API は使いません。一括取得もしません。

## X のブックマークが多すぎて古いものが取り込めません
X のブックマーク一覧には、表示件数の上限があるとされています。800〜1000 件程度と言われていますが、公式には確認できていません。上限を超えて見えなくなった分は、画面に出てこないため取り込めません。**日常的にこまめに取り込む**ことをおすすめします。

## 別のパソコンと同期できますか？
**自動の同期はありません。** 手動で移行できます。

1. 元の端末で manager を開き、左下の「エクスポート」で JSON ファイルを保存
2. 移行先の Chrome (PostShelf 入り) で manager を開き、「インポート」でその JSON を選ぶ
3. 同じ ID のフォルダ・ポストは上書き、それ以外は追加 (マージ) されます

エクスポートの形式は言語に依存しません。

## 今後の課題: クラウド同期
複数端末での自動同期 (クラウド同期) は、PostShelf の「データは端末内のみ」「外部通信なし」という方針と衝突するため、**現時点では対象外**です。実現するなら、ユーザーが明示的に有効にするオプトイン方式や、`chrome.storage.sync` (Chrome アカウント経由、容量制限が小さい)、ユーザー自身のストレージを使う方式など、プライバシー方針との両立を含めて別途検討が必要です。

## サイドパネルで開けますか？
Chrome 114 以降で、popup の「サイドパネルで開く」から開けます。設定で、ツールバーアイコンのクリック時の動作 (ポップアップ / サイドパネル) を切り替えられます。
