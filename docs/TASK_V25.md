## 1. 説明の短文化 (v25-A)
- 「X のブックマークと連動する」の説明 (`syncNative` の説明) を、意味を変えずに、短い文 3 つの箇条書きと、1 行の補足に分ける。
  - フォルダに保存したとき、X 標準のブックマークも付けます。
  - すべてのフォルダから外したとき、X 側のブックマークも外します。
  - PostShelf が画面上のブックマークボタンを押すのは、操作したポスト 1 件につき 1 回だけです。
  - (補足) 初期値はオフです。
- ほかの設定の説明 (`setting-desc`) にも、行の長さの上限 (`max-width: 40em` 前後) を付け、画面を広げても、1 行が間延びしないようにする。スイッチとボタンの位置は、いまのまま (右端) にする。
- 説明の言葉は、元の文から足さない。「PostShelf が」の主語を落とさない。

## 2. 欄の分割と順番 (v25-B)
### 「データ」の欄の分割
いまの「データ」の欄は、性質の違う 5 つ (エクスポート / インポート、自動取り込み、バージョン、更新の手順、GitHub) を抱えている。次の 3 つに分ける。
- **データの保存と移行**: エクスポート、インポート。説明を 1 行 (「保存したポストとフォルダを、ファイルに書き出したり、読み込んだりします。」)。
- **ブックマークの自動取り込み**: 「自動取り込みを使う」のスイッチ、開始のボタン、規約上の注意。
- **PostShelf について**: バージョン、更新の手順 (「更新と手動インストールの手順」のリンクを含む)。GitHub ボタンは、ここには置かない (3 を参照)。

### 欄の順番
上から、次の順にする。小さな見出し (グループ) の下に、欄を並べる。

| グループ | 欄 |
|---|---|
| 保存 | 1. X のブックマークと連動する / 2. 標準ブックマークボタンの動作 / 3. 長いポストの全文 (v24 で追加) / 4. 画像のキャッシュ |
| 取り込み | 5. ブックマークの自動取り込み |
| 表示と動作 | 6. ツールバーアイコンのクリック時の動作 |
| データ | 7. データの保存と移行 |
| 情報 | 8. X の画面構造 / 9. PostShelf について |
| 初期化と削除 | 10. 設定の初期化 / 11. 危険な操作 |

- 「標準ブックマークボタンの動作」は、「連動する」と独立した設定。入れ子にしない。
- 「長いポストの全文」の欄は、v24 で足した設定 (スイッチ、全文を取得していない件数、「いま取得する」) をそのまま移す。v24 が、まだ入っていない場合は、その欄を飛ばして、あとから足せるようにしておく。
- 危険な操作は、いまと同じく、赤い枠で、一番下。
- 診断の入り口 (`#diagnostics` で「X の画面構造」へ移る動作) と、x.com の自動取り込みの案内からの `#autocollect` の動作は、いまのまま動くこと。

### ジャンプのリンク
- 設定の上部に、グループの名前 (保存 / 取り込み / 表示と動作 / データ / 情報 / 初期化と削除) を並べた「目次」を置く。押すと、そのグループの見出しまでスクロールする。
- **URL のハッシュ (`#...`) は使わない。** 管理画面は、`#settings` `#diagnostics` `#autocollect` を、画面の切り替えに使っている (`hashchange` の処理がある)。目次は `<button>` にして、`scrollIntoView` で動かす。
- `prefers-reduced-motion` のときは、滑らかなスクロールにしない。移動したあと、見出しにフォーカスを移す (`tabindex="-1"`)。
- 目次は、`<nav aria-label>` にする。画面が狭いときは、折り返して並べる。上に固定 (`position: sticky`) してよいが、本文を隠さないこと。
- グループの見出しは、小さな文字で、`<h3>` などの見出し要素にする (欄の `<legend>` は、そのまま残す)。1 つの欄しかないグループでも、見出しは省かない (目次と対応させるため)。

## 3. GitHub ボタンの移動 (v25-C)
- 設定の中の「GitHub で見る」ボタンを外す。
- 左のメニューの、一番下の「設定」の下に、小さな丸いボタン「GitHub」(GitHub のロゴ + 外部リンクの印) を置く。どの画面にいても見える。
  - `<a>`、`target="_blank"`、`rel="noopener noreferrer"`、URL は、v23 の定数 (`src/shared/links.ts`) を使う。
  - 左のメニューが狭いとき (幅が足りないとき) は、ロゴだけにする。名前は `aria-label` に残す (「GitHub で見る (新しいタブで開きます)」。v23 の文言を再利用する)。
  - サイドパネルには置かない。
- v23 で作ったアイコンと文言は、再利用する。新しい文言は増やさない。

## 守ること
- 保存データの形、設定の形、各設定の動作は変えない。変えるのは、見た目、欄の順番、文言、目次だけ。
- 必須の権限は増やさない。外部通信のコードは足さない。
- キーボード操作 (Tab 順は、目次 → 各グループの上から下の順) と、`aria-*`、`role` (スイッチの `role="switch"` を含む) を保つ。ライト / ダークのどちらでも読める。
