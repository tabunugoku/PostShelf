## Fixed
- The manager, the side panel, the popup and the parts PostShelf shows on x.com now share one scale. Spacing, heights, corner radius, font weight, icon size and motion use the same values on every screen. Colors and wording are unchanged
  - Less bold text. Selected folders, headings and button labels are only slightly heavier than normal text. The heaviest text is now only the author name of a post
  - Heights are now consistent. Folder rows in the sidebar are 36px; buttons, menu rows and filter chips are 32px
  - In Settings, each group of items is one panel, with lines between the rows
  - The numbers in the popup are left-aligned. "Sort Unsorted" now has an arrow, so you can tell it is a button
  - The text, borders and shadows of the save popover on x.com and of the automatic import panel now match the manager. In the automatic import panel, the progress bar keeps moving while the import runs
- When you chose several posts with "Select" and opened "Change folders", "Add folder" and "Confirm" went off the screen and could not be pressed if you had many folders. The menu now fits the height of the screen, and only the folder list scrolls
- In a quote post, your own images and videos are now shown before the quoted post. The order is: the text, your images and videos, then the quoted post

No required permissions or outside communication were added. The format of saved data and of exported JSON (`version: 2`) is unchanged.

## Install / update
For the steps, see [docs/INSTALL.en.md](https://github.com/tabunugoku/PostShelf/blob/main/docs/INSTALL.en.md). Before updating, exporting your data from "Data" in Settings is a good idea.

When you update, do not remove the extension. Overwrite the same folder and press "Reload", and your saved data is kept. Chrome 130 or later is required.

## 修正
- 管理画面・サイドパネル・ポップアップ・x.com 上の部品の見た目を、同じ尺度にそろえた。余白・高さ・角丸・文字の太さ・アイコンの大きさ・動きを、すべての画面で同じ値にした。配色と文言は変えていない
  - 太字を減らした。選択中のフォルダ・見出し・ボタンの文字は、ふつうより少し太い程度にした。いちばん太い文字は、ポストの投稿者名だけにした
  - 行の高さをそろえた。サイドバーのフォルダの行は 36px、ボタン・メニューの行・絞り込みのチップは 32px
  - 設定は、項目のまとまりごとに 1 枚の面にし、行を線で区切った
  - ポップアップの数の欄を左寄せにした。「未分類を仕分ける」には矢印を付け、押せることが分かるようにした
  - x.com の保存のポップオーバーと、自動取り込みのパネルの文字・枠線・影を、管理画面と同じにした。自動取り込みのパネルでは、取り込み中の棒が動き続ける
- 「選択」で複数のポストを選んで「フォルダを変更」を開いたとき、フォルダが多いと「フォルダを追加」と「確定」が画面の外に出て押せなかった。メニューを画面の高さに収め、フォルダの一覧だけをスクロールするようにした
- 引用ポストで、自分の画像・動画を引用元より前に出すようにした。並びは、本文、自分の画像・動画、引用元の順になる

必須の権限と外部への通信は増やしていません。保存データの形と、書き出す JSON の形 (`version: 2`) は変えていません。

## インストール・更新
手順は [docs/INSTALL.md](https://github.com/tabunugoku/PostShelf/blob/main/docs/INSTALL.md) を参照してください。更新の前に、設定の「データ」からエクスポートしておくと安心です。

更新するときは、拡張機能を削除しないでください。同じフォルダに上書きして「再読み込み」を押せば、保存したデータはそのまま残ります。Chrome 130 以降が必要です。
