## Added
- Added "Check for new versions" to "About PostShelf" in Settings (off by default). When it is on, PostShelf asks GitHub for the latest version number at most once a day when you open the manager or the side panel, and if a newer version exists, it shows a notice and a link to the release page. The toolbar popup does not ask GitHub; it only shows the result of the last check. No data is sent, but GitHub sees the time of the check, your IP address, your browser type, and that the request comes from PostShelf. Updates are never installed automatically

## Fixed
- On x.com, when you had many folders, the popover went off the screen and did not follow the post when you scrolled. Now only the folder list scrolls inside the popover, and the filter at the top and "Add folder" and the other controls at the bottom stay in place. In "Create folder", "Cancel" and "Create" are no longer hidden. The popover follows the post and shrinks to fit the free space. It closes when there is not enough space or when the post leaves the screen
- With two x.com tabs open on different accounts, the account shown in the manager could switch back and forth between the two accounts. Now only the tab you are using (visible on the screen and focused) records the account you last saw on x.com. An account seen for the first time also appears in the manager's account list only when you use that tab
- PostShelf is now lighter when you have many saved posts and folders. On x.com and in the manager, it reads saved data again less often, and does less work counting posts, calculating folders and redrawing cards. x.com tabs that are not visible read saved data again only after they become visible

No required permissions were added. The format of saved data is unchanged. The only outside communication added is the request to GitHub when "Check for new versions" is on (off by default).

## 追加
- 設定の「PostShelf について」に「新しいバージョンを確かめる」を追加した (初期値はオフ)。オンにすると、管理画面とサイドパネルを開いたときに 1 日 1 回まで、GitHub に最新のバージョン番号を問い合わせ、新しいバージョンがあれば案内とリリースのページへのリンクを出す。ポップアップは問い合わせず、前回の結果だけを出す。送るデータはないが、GitHub には、確かめた時刻・IP アドレス・ブラウザの種類と、PostShelf からの問い合わせであることが伝わる。更新は自動では行わない

## 修正
- x.com のポップオーバーで、フォルダが多いと画面の外へはみ出し、スクロールしてもついてこない不具合。フォルダの一覧だけをポップオーバーの中でスクロールし、上の絞り込みと下の「フォルダを追加」などは動かないようにした。「フォルダを作成」でも、「キャンセル」と「作成」が隠れない。ポップオーバーは投稿についていき、空きに合わせて高さを縮める。空きが足りなくなったときや、投稿が画面の外へ出たときは閉じる
- 別々のアカウントの x.com のタブを 2 つ開いていると、管理画面で表示するアカウントが 2 つのアカウントの間で切り替わることがある不具合。x.com で最後に見たアカウントは、いま操作しているタブ (画面に見えていて、フォーカスのあるタブ) だけが記録するようにした。初めて見るアカウントが管理画面のアカウントの一覧に出るのも、そのタブを操作したときになる
- 保存したポストやフォルダが多いときの動きを軽くした。x.com と管理画面で、保存データを読み直す回数と、件数・フォルダの計算、カードの描き直しを減らした。見えていない x.com のタブは、見えるようになってから読み直す

必須の権限は増やしていません。保存データの形も変えていません。外部への通信は、「新しいバージョンを確かめる」をオンにしたときの GitHub への問い合わせだけを足しました (初期値はオフ)。
