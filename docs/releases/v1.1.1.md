## Added
- The screen reader names (`aria-label`) of the icon and color buttons now use text in the 8 languages (previously class names or hard-coded hex values)

## Fixed
Fixes for 15 code review findings, and a fix for the date shown during automatic import.

- During automatic import, "now at posts from around ..." stayed at an old date when old posts had been reposted (it now shows the median of the dates of the last 10 posts; "the oldest post" shown after the import ends is unchanged)
- Switching accounts during automatic import put the collected posts into another account's "Unsorted"
- Stricter checks on import (data missing required fields, `javascript:` URLs and `http:` images are dropped; posts with an empty `folderIds` go to "Unsorted")
- When fetching full text, a success that had already been applied was counted as a failure, and fetching stopped after repeated failures. The stop button increased the failure count
- "Fetch now" skipped the items that had just failed and finished without doing anything
- The likes tab (`/i/history/likes`) was reused, and automatic import did not start
- Speed on x.com: the processing that reread saved data for each button is now shared
- Saving during import rewrote every item; it now saves only the changes
- In the side panel, "Save the open post" did not put the post in "Unsorted" when you removed it from all folders
- After switching accounts, the image cache's scope was swapped
- In the popover, "Remove" after switching accounts, and things shown twice
- Failures of bulk actions in the manager were not shown to the user
- Mismatches in full text requests during import (posts that failed to save were requested; collapsed posts were missed after reloading)
- The viewer did not open for posts with no images or videos
- The folder count in the toolbar popup was one more than in the manager

No required permissions were added. The format of saved data is unchanged.

## 追加
- アイコンと色のボタンの読み上げ名 (`aria-label`) を、8 言語の文言にした (これまでは、クラス名や 16 進数の直書き)

## 修正
コードレビューの指摘 15 件の修正と、自動取り込み中の日付の表示の修正です。

- 自動取り込み中の「いま ○○ ごろの投稿です」が、古いポストのリポストで古い日付のまま残る不具合 (直近 10 件の投稿日時の中央値を出すようにした。終了後の「いちばん古い投稿」は従来どおり)
- 自動取り込みの途中でアカウントを切り替えると、集めた分が別のアカウントの「未分類」に入る不具合
- インポートの検証を強化 (必須項目がないデータ、`javascript:` の URL、`http:` の画像を捨てる。`folderIds` が空のものは「未分類」にする)
- 全文の取得で、すでに更新済みの成功が失敗として数えられ、連続失敗で止まる不具合。停止ボタンで失敗が増える不具合
- 「いま取得する」が、直前に失敗した項目を飛ばして何もせずに終わる不具合
- いいね (`/i/history/likes`) のタブが再利用され、自動取り込みが始まらない不具合
- x.com の画面の速度: ボタンごとに保存データを読み直していた処理を共有
- 取り込みの保存で、全件を書き直していた処理を差分の保存に変更
- サイドパネルの「いま開いているポストを保存」で、すべてのフォルダを外しても「未分類」にならない不具合
- アカウントを切り替えたあと、画像のキャッシュの範囲が入れ替わる不具合
- ポップオーバーで、アカウント切替後の「外す」と二重表示の不具合
- 管理画面の一括操作が失敗しても、利用者に伝わらない不具合
- 取り込みの全文要求のずれ (保存に失敗した分が要求に入る、再読み込み後にたたまれたポストを拾えない)
- 画像・動画が空のポストで、ビューアが開かない不具合
- ツールバーのポップアップのフォルダ数が、管理画面より 1 多い不具合

必須の権限は増やしていません。保存データの形も変えていません。
