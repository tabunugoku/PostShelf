## 追加
- X のポストを、名前・アイコン・色を選べるフォルダに分類 (1 つのポストを複数のフォルダに入れられる)
- ポスト / リスト / グリッド表示、検索、並べ替え、絞り込み
- 複数選択による一括操作、ドラッグ&ドロップ、取り消し、キーボード操作
- X のブックマークと連動するモード、標準のブックマークボタンを置き換えるモード
- サイドパネル、いま開いているポストの保存
- 画像・動画のビューア、画像のキャッシュ (ブラウザ内 / 選んだフォルダ)
- ブックマーク一覧 (`/i/history`) からの取り込み、複数アカウントの切り替え
- JSON のエクスポート / インポート、設定の初期化とすべてのデータの削除
- X の画面構造の自己診断
- 8 言語 (日本語・英語・中国語 簡体字 / 繁体字・韓国語・スペイン語・ポルトガル語 ブラジル・フランス語)
- 新しいアイコン、固定の拡張機能 ID、手動インストールの手順書
