## Added
- Sort X posts into folders with a name, icon and color of your choice (one post can be in several folders)
- Post, list and grid views; search, sorting and filters
- Bulk actions on selected posts, drag and drop, undo, and keyboard controls
- A mode that works together with X bookmarks, and a mode that replaces the standard bookmark button
- Side panel, and saving the post you have open
- Image and video viewer; image cache (inside the browser, or in a folder you choose)
- Import from the bookmarks page (`/i/history`); switching between several accounts
- JSON export and import; resetting settings and deleting all data
- Self-check of the X page structure
- 8 languages (Japanese, English, Simplified Chinese, Traditional Chinese, Korean, Spanish, Brazilian Portuguese, French)
- A new icon, a fixed extension ID, and a guide for manual installation

## Fixed
- There are no fixes, as this is the first release.

## Install / update
For the steps, see [docs/INSTALL.en.md](https://github.com/tabunugoku/PostShelf/blob/main/docs/INSTALL.en.md). Before updating, always export your data from "Data" in Settings.

## 追加
- X のポストを、名前・アイコン・色を選べるフォルダに分類 (1 つのポストを複数のフォルダに入れられる)
- ポスト / リスト / グリッド表示、検索、並べ替え、絞り込み
- 複数選択による一括操作、ドラッグ&ドロップ、取り消し、キーボード操作
- X のブックマークと連動するモード、標準のブックマークボタンを置き換えるモード
- サイドパネル、いま開いているポストの保存
- 画像・動画のビューア、画像のキャッシュ (ブラウザ内 / 選んだフォルダ)
- ブックマーク一覧 (`/i/history`) からの取り込み、複数アカウントの切り替え
- JSON のエクスポート / インポート、設定の初期化とすべてのデータの削除
- X の画面構造の自己診断
- 8 言語 (日本語・英語・中国語 簡体字 / 繁体字・韓国語・スペイン語・ポルトガル語 ブラジル・フランス語)
- 新しいアイコン、固定の拡張機能 ID、手動インストールの手順書
