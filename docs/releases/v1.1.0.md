## Added
- Automatic bookmark import (it starts only after you agree in a confirmation dialog; you can pause or stop it, and it stops when it detects a limit from X)
- Saving to "Unsorted"
- A menu in the save popover for adding a new folder
- Fetching the full text of long posts (a background tab is opened briefly when you save; it can be turned off in Settings), collapsing and expanding, and links in the text
- Video and image labels (grid, list, post view and side panel)
- Settings are organized into 6 groups, with a table of contents. A link to GitHub was added to the left menu

## Fixed
- Consistency of saved data ("Unsorted" used together with other folders, deleting folders, simultaneous writes)
- Behavior of automatic import (loading saved IDs, counting failures, several tabs, detecting the end)
- Posts with only a video appeared under the "has images" filter
- The import result bar came back after you closed it
- Menus were cut off at the edge of the screen
- Japanese wording, and carrying it over to the other languages

## Install / update
For the steps, see [docs/INSTALL.en.md](https://github.com/tabunugoku/PostShelf/blob/main/docs/INSTALL.en.md). Before updating, always export your data from "Data" in Settings.

## 追加
- ブックマークの自動取り込み (確認ダイアログで同意したときだけ開始。一時停止・停止ができ、X の制限を検知したら止まる)
- 「未分類」での保存
- 保存ポップオーバーから、新しいフォルダを追加するメニュー
- 長いポストの全文の取得 (保存するときに裏のタブを短く開く。設定でオフにできる)、たたむ・広げる、本文中のリンク
- 動画と画像の札 (グリッド・リスト・ポスト表示・サイドパネル)
- 設定画面を 6 つのグループに整理し、目次を追加。GitHub へのリンクを左のメニューに追加

## 修正
- 保存データの整合 (「未分類」と他のフォルダの併用、フォルダ削除、同時書き込み)
- 自動取り込みの動き (保存済み ID の読み込み、失敗の数え方、複数タブ、終わりの判定)
- 動画だけのポストが「画像あり」の絞り込みに出る不具合
- 取り込みの結果の帯を閉じても、再表示される不具合
- メニューが画面の端で切れる不具合
- 日本語の文言と、他言語への反映

## インストール・更新
手順は [docs/INSTALL.md](https://github.com/tabunugoku/PostShelf/blob/main/docs/INSTALL.md) を参照してください。更新の前に、設定の「データ」から必ずエクスポートしてください。
