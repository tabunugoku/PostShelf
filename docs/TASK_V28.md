## A. 保存ポップオーバー (`src/content/popover.ts`、`src/shared/folderPicker.ts`)

### A-1. 削除とサイドパネルをアイコンだけにする
- いまの下部は、「サイドパネルで開く」(文字つきの行) と、区切り線のあとの赤い「PostShelf から外す」の 2 行。これを、区切り線の下の 1 行にまとめる。左端にサイドパネル、右端に削除のアイコンボタンを置く (`justify-content: space-between`)。
- アイコンは Tabler の `ti-layout-sidebar-right` と `ti-trash`。削除は赤 (既存の危険色)。名前は `aria-label` / `title` に入れる。
- 削除の動作: 押したら、確認なしで `removeBookmark()` を実行し、ポップオーバーを閉じる。そのあとの処理 (`requestPrune()`、連動モードのときの X 側の解除、アカウント切替後の安全確認) は、いまのまま。削除後の表示は出さない。x.com 側のボタンは、保存の変更の購読で未保存の見た目に戻る (いまの経路を使う。戻らなければ直す)。
- `flatButton` は、manager の他の画面でも使われていないか確認し、使われていなければ削除せず、そのまま残す (他の版で使う可能性があるため)。

### A-2. 文言の変更
- `removeFromPostShelf` の文言を、各言語で「保存の削除」の意味にする。ja は「PostShelf の保存を削除」。ほかの言語も、「ポストを外す / 解除する」ではなく、「保存を削除する」の意味にそろえる (X のポストは消えない、という意味が崩れないように)。
- 「外す」は、フォルダのチェックを外す操作だけに使う。`docs/FAQ.md` / `README.md` / `docs/MANUAL_TEST.md` などに「PostShelf から外す」があれば、新しい名前に直す (`grep` で探す)。

### A-3. フォルダの絞り込みと「最近使った」
- フォルダが 8 つ以上のとき、一覧の上に絞り込み欄を出す。入力で、名前に一致するフォルダだけを残す。大文字小文字と全角半角は区別しない。ポップオーバーを開いたとき、絞り込み欄にフォーカスを当てる。
- フォルダが 6 つ以上のとき、一覧の先頭に「最近使った」(最大 3 つ) を出す。そのフォルダは、下の「すべてのフォルダ」には重ねて出さない (どちらでも同じチェックの状態にする)。
- 「最近使った」は、設定に任意の項目 `recentFolderIds?: string[]` (最大 3 件、新しい順) を足して持つ。保存でフォルダを選ぶたびに、先頭へ入れ直す (重複なし。「未分類」と「すべて」は入れない。存在しないフォルダは表示で飛ばす)。`src/shared/settings.ts` の正規化にも足し、無い・不正な値は空にする。
- 上の 2 つの閾値 (8 と 6) は、定数にする。
- 一覧のヘッダーに、保存の状態を出す: 保存済みなら「✓ N つに保存済み」(N は「未分類」を除く選択数)。「未分類」だけなら「✓ 未分類に保存済み」。未保存なら何も出さない。
- キーボード: ↑↓ で行を移動、Space で入れる / 外す (既存のチェックボックスの動作)、Esc で閉じる (既存)。絞り込み欄で ↓ を押すと、最初の行へ移る。
- manager の「フォルダを変更」でも `createFolderPicker` を使っている。この版では、絞り込みと「最近使った」を**オプションで有効にする**形にし、x.com のポップオーバーだけで有効にする (manager の見た目は変えない)。

## B. 自動取り込みのパネル (`src/content/autocollectPanel.ts`)
- 実行中 (`running`) と一時停止 (`paused`) のパネルに、「畳む」ボタンを足す。押すと、1 行の小さなバー (幅は内容なり、右下) になる。バーには、状態の点、「取り込み中 · 取り込み N · 失敗 M」、「開く」ボタンを出す。畳んでも、取り込みは止まらない。
- 畳んだ状態は、そのページを開いているあいだだけ覚える (モジュールの変数。保存しない)。パネルが `limit` / `done` / `stopped` / `countdown` になったら、自動で開く (見落としたくない情報なので)。
- 畳んだバーも `role="status"` / `aria-live="polite"` にする。ボタンは 44px の高さ。
- いまのパネルが出している 3 つの数 (取り込み / スキップ / 失敗) は、そのまま。足さない。
- 新しい文言 (8 言語): `acBtnCollapse` (畳む)、`acBtnExpand` (開く)、`acCollapsedLine` (取り込み中 · 取り込み $IMPORTED$ · 失敗 $FAILED$)。
- 畳んだバーがあっても、右下の取り込みボタンの隠し方 (`data-postshelf-panel`) は、いまのまま (パネルかバーがある間は隠す)。

## C. ツールバーのポップアップ (`src/popup/index.tsx`、管理画面の `src/manager/App.tsx`)
- 「フォルダ」のタイル (見ても行動に結びつかない数) を、「未分類」のタイルに替える。数字と「未分類を仕分ける」を出し、押すと管理画面を「未分類」の表示で開く。件数は、管理画面の左のメニューの「未分類」と**同じ定義・同じ関数**で数える (v26 で、フォルダ数を左のメニューに合わせたのと同じやり方)。未分類が 0 件のときは、タイルを控えめな見た目にし、押しても何もしない (または管理画面を開くだけ)。
- ヘッダーの下に検索欄を置く。入力して Enter で、管理画面を開き、その検索語を入れた状態にする。
- 管理画面の入口を足す: URL のハッシュ `#inbox` (未分類の表示で開く) と `#q=<URI エンコードした検索語>` (検索語を入れて開く)。既存のハッシュ (`#settings` `#diagnostics` `#autocollect`) は、そのまま動かす。ハッシュは、読み取ったら `history.replaceState` で消す。初期表示で `lastFolderId` を読む処理と順序が競合しないようにする (ハッシュが優先)。
- 「診断情報をコピー」は、ポップアップから外し、設定の「情報」のグループに移す (すでに設定にあれば、ポップアップのボタンだけを外す)。ポップアップの下の行は「設定」だけにする。
- 「最近保存した 3 件」の各行に、入っているフォルダの色の点を付ける (「未分類」は枠だけの点)。
- 新しい文言 (8 言語): `popupInbox` (未分類を仕分ける)、`popupSearch` (保存したポストを検索)。
