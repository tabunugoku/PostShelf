# PostShelf のインストールと更新 (手動インストール)

PostShelf は Chrome Web Store では配布していません。Chrome の「デベロッパーモード」で、zip を展開したフォルダを読み込んで使います。
English: [INSTALL.en.md](INSTALL.en.md)

- 拡張機能 ID: `aglgbnegdnodlmbmlfmaagjkneokagnc`
  - 正しく入っていれば、`chrome://extensions` の PostShelf の欄に、この ID が出ます。
  - この ID は、拡張機能に埋め込んだ公開鍵 (manifest の `key`) から決まります。**フォルダを移したり、展開し直したりしても変わりません**。データは、この ID ごとに Chrome が保存します。

**いちばん大事なこと**: 更新するときは、拡張機能を**削除しない**でください。削除すると、保存したポスト・フォルダも消えます。同じフォルダに上書きして、「再読み込み」を押します。

## 1. はじめて入れるとき

1. zip を入手します。
   - GitHub の Releases (`https://github.com/tabunugoku/PostShelf/releases`) の最新版から `postshelf-x.y.z.zip` を保存します。または、渡された zip を使います。
2. 展開する場所を決めます。**この場所を、今後ずっと使います**。例: `C:\PostShelf` (Mac なら `~/PostShelf`)。
   - 「ダウンロード」フォルダなど、あとで消してしまいそうな場所は避けてください。
   - zip を、決めたフォルダに展開します。フォルダの直下に `manifest.json` が見える状態にします (`PostShelf` の中に `PostShelf` が重なっていると、読み込めません)。
3. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、手順 2 のフォルダを選びます。
5. 一覧に PostShelf が出ます。**ID が、このページの先頭の ID と同じか**確かめます。
6. ツールバーの拡張機能 (パズルのアイコン) から、PostShelf の「ピン留め」を押します。

## 2. 更新するとき (毎回この手順)

1. **バックアップ**: PostShelf の管理画面 → 設定 → 「データ」 → 「エクスポート」を押し、JSON ファイルを保存します (念のためです。必ず行ってください)。
2. 新しい版の zip を入手します (1 の手順 1)。
3. **同じフォルダ**に、zip の中身を**上書き**して展開します。フォルダを変えたり、別の場所に展開したりしないでください。
4. `chrome://extensions` を開き、PostShelf の「再読み込み」(↻) を押します。
5. 管理画面を開くと、上部に「PostShelf を更新しました (x.y.z)」と出ます。設定の「データ」にもバージョンが出ます。

やってはいけないこと:
- **削除** (「削除」ボタンで消すと、データも消えます)
- **フォルダを変える** (読み込み直しになります。ID は変わりませんが、迷いの元です。上書きに統一してください)

## 3. ID を固定した版 (`key` 入りの版) に切り替える (1 回だけ)

これまでの版は、ID が「読み込んだフォルダの場所」から決まっていました。そのため、フォルダを動かすと別の拡張機能として扱われ、保存したデータが引き継がれませんでした。
この版から ID を固定しました。**そのため、固定の ID の版に切り替える 1 回だけは、旧版のデータが自動では引き継がれません**。次の手順で、エクスポートしてインポートします。2 回目以降の更新では、ID が変わらないので、データは残ります。

1. **旧版で、エクスポートする**: 旧版の PostShelf の管理画面 → 設定 → 「データ」 → 「エクスポート」。`postshelf-日付.json` が保存されます。
   - ファイルができたことを、ダウンロードの一覧などで確かめてください。
   - 画面: ![設定の「データ」](screenshots/tab-settings-light.png)
2. 旧版を、`chrome://extensions` で**オフ**にします (または「削除」)。エクスポートのファイルがあることを確認してからにしてください。旧版と新版を両方オンにすると、x.com のボタンが二重になります。
3. 新しい版を、「1. はじめて入れるとき」の手順で、決めたフォルダに入れます。ID が、このページの先頭の ID と同じか確かめます。
4. **新版で、インポートする**: 新版の管理画面 → 設定 → 「データ」 → 「インポート」で、手順 1 のファイルを選びます。件数が表示されます。
5. ポストとフォルダが見えることを確かめたら、旧版を削除して構いません。

メモ:
- 画像のキャッシュ (任意の機能) は、エクスポートに含まれません (URL のみ)。「自分で選んだフォルダ」に保存している画像は、フォルダに残ります。
- 設定 (標準ブックマークボタンの動作など) は、エクスポートに含まれません。新版で、もう一度選んでください。

## 4. Chrome に出ることがある確認

デベロッパーモードで読み込んだ拡張機能がある状態で Chrome を起動すると、「デベロッパーモードの拡張機能を無効にしますか」のような確認が出ることがあります。これは、デベロッパーモードで読み込んだ拡張機能に対する Chrome の仕様です。出たときは「キャンセル」を選ぶと、そのまま使えます。Chrome のバージョンによって、表示や選択肢は異なります。

## 5. うまくいかないとき

- **読み込みでエラーが出る**: 選んだフォルダの直下に `manifest.json` があるか確かめます。フォルダが 1 段深い場合は、中のフォルダを選び直します。Chrome のバージョンは 114 以上が必要です。
- **アイコンが出ない**: ツールバーの拡張機能 (パズルのアイコン) から、PostShelf を「ピン留め」します。
- **データが消えたように見える**: 多くの場合、別の拡張機能として読み込まれています。`chrome://extensions` の PostShelf の ID が、このページの先頭の ID (`aglgbnegdnodlmbmlfmaagjkneokagnc`) と同じか見比べてください。
  - ID が違う → 旧版 (ID が固定される前の版) を開いています。旧版の管理画面から「エクスポート」して、新版で「インポート」します (3 の手順)。
  - ID が同じ → 管理画面の左上のアカウントの表示を確認します (別のアカウントのデータを見ていることがあります)。
- **更新したのに変わらない**: `chrome://extensions` で、PostShelf の「再読み込み」(↻) を押したか確かめます。開いている x.com のタブは、再読み込み (F5) が必要です。
- 画面の表示が、X の仕様変更で壊れたとき: 設定の「X の画面構造」から、診断情報をコピーして報告できます。
