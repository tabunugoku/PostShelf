# 追加タスク (v4): x.com 上の操作ボタン改善 + manager でのブックマーク整理

前提: v3 は `claude/serene-johnson-j5tpe7` で実装済み (CI 成功)。続きで作業する (最初に `origin/main` をマージ)。

## 実機 (x.com ホーム、ダークテーマ) で確認できたこと
- 「▾」は約 8px の青い三角で、X 標準のブックマークボタン (19x26px) のすぐ右にある。クリック判定が極小で、押そうとして標準ブックマークを押してしまい、意図せず X のブックマークが付いた (実際に発生)
- 原因: `src/content/popover.ts` のボタンが `font-size:12px;padding:4px` の文字 (`▾`) だけ
- X 標準のブックマークボタンを押すと、X 自身が「ブックマークに追加しました / フォルダに追加」のトーストを出す (X Premium のフォルダ機能の案内)。PostShelf の「フォルダ」と紛らわしい

## A. x.com 上の PostShelf ボタンを押しやすくする
1. 文字 `▾` をやめ、アイコンボタンにする (Tabler の `ti-folder-plus` か `ti-folders`)。X の他の操作アイコン (返信/リポスト/いいね/ブックマーク/共有) と同じ見た目のルールにする
   - 見えるアイコンは 18〜20px、クリック判定は 34x34px 以上
   - hover で X と同様の丸い背景 (X のアクセント色の薄い透過)
   - 保存済み (1 つ以上のフォルダに入っている) ポストはアイコンの色を変えて分かるようにする。可能ならフォルダ数のバッジか、最初のフォルダの色
   - `aria-label` と `title` は i18n (ja/en/他言語)
2. 配置: X 標準のブックマークボタンの右隣、共有ボタンとの間。標準ボタンと判定領域が重ならないよう 4px 以上の余白。操作列の幅が足りない狭い画面でも崩れないこと
3. ポストの個別ページ (`/status/...`) や、ブックマーク一覧 `/i/bookmarks` でも同じ位置・同じサイズで表示される
4. ポップオーバーは今のままでよいが、ボタンの真下に出し、画面端ではみ出さないよう位置を補正 (すでに補正があれば維持)
5. fixture テスト: ボタンの判定領域サイズ (CSS で 34px 以上)、標準ボタンの再クリックを誘発する重なりがないこと、二重注入されないこと

## B. manager でブックマークを整理できるようにする
目的: X に戻らなくても、拡張の管理画面だけで保存済みポストを整理できる。

1. 各ポスト (ポスト表示/リスト表示の両方) に操作を追加
   - 所属フォルダのチップ (今も表示している) をクリックで、そのフォルダから外す
   - 「フォルダを変更」ボタン → x.com のポップオーバーと同じチェックボックス式の選択 (共通コンポーネント化して再利用)
   - 「削除」(PostShelf から消す。X 側には触らない) 。確認ダイアログは `confirm()` を使わず、アプリ内の確認 UI にする
2. 複数選択: 行頭のチェックボックスで複数選択 → 上部のバーに「N 件選択中」「フォルダに追加」「フォルダから外す」「削除」「選択解除」
   - Shift+クリックで範囲選択、Ctrl/Cmd+A で全選択 (検索結果内)
3. ドラッグ&ドロップ: ポスト (複数選択も可) を左のフォルダ行にドロップすると追加。Alt を押しながらなら移動 (今のフォルダから外して追加)
4. 左サイドバー: フォルダのドラッグで並べ替え (`order` を更新)。「未分類」は常に「すべて」の次
5. 元のポストを開く (外部リンク) は新しいタブで。リンクに `rel="noopener noreferrer"`
6. 取り消し: 削除・移動の直後に「元に戻す」トースト (5 秒)
7. 件数表示が操作後すぐ更新される。ストレージ更新は `src/shared/storage.ts` の既存関数を使い、複数件の操作は 1 回の書き込みにまとめる (まとめ関数を追加)
8. キーボード操作: 矢印キーで行移動、Space で選択、Delete で削除 (確認 UI つき)
9. 単体テスト: 一括追加/一括解除/一括削除、並べ替え、取り消し、「すべて」「未分類」の特殊扱い

## C. 見づらさの改善 (manager / popup / ポップオーバー)
実機の x.com の見え方は上記のとおり。manager ページは `chrome-extension://` のためクラウドからは確認できないので、以下を基準に自己点検し、スクリーンショットを更新する。
1. 文字は 14px 以上、行間 1.5 以上。薄い灰色の補助文字もコントラスト比 4.5:1 以上 (ライト/ダーク両方)
2. 選択中のフォルダ、選択中のアイコン、選択中の色は、色だけに頼らず枠線や太さでも区別できる
3. ボタン・アイコンのクリック判定は 32px 以上
4. フォーカスリング (キーボード操作時) を必ず見えるようにする
5. ポスト表示で、本文・画像・所属フォルダの階層が分かる余白にする (docs/mockups/manager.html を基準)
6. 更新したスクリーンショットを `docs/screenshots/` に保存 (ライト/ダーク、ポスト表示/リスト表示、複数選択中、編集パネル開)
