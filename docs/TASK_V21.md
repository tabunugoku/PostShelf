# TASK v21: ツールバーのポップアップの見た目

v20 が終わったあとに実施する。見た目 (CSS と DOM の組み立て) の小さな改善だけを行う。保存データの形と動作は変えない。

基準は `docs/mockups/ui-polish.html` の 8 の after (ユーザーが「採用」と決めた)。モックは見た目の案であり、ピクセルの指定ではない。実際の配色・余白は、既存のポップアップの CSS 変数に合わせる。

対象は `src/popup/index.tsx` と、そのスタイル。

## 変えること
1. **ヘッダー**: 右端に、現在のアカウントを `@ハンドル` の小さな丸い枠で出す。いまの「アカウント: @…」の 1 行は無くす。
   - アカウントを判定できていないとき (`UNKNOWN_ACCOUNT_ID`) だけ、既存の「アカウント未設定」の文言を、同じ枠で出す。
   - 長いハンドルは、枠の中で `text-overflow: ellipsis` にする。ヘッダーの幅からはみ出さない。
2. **件数**: 「17 件 · 1 フォルダ」の 1 行をやめ、2 つの小さなタイル (大きい数字 + 下に「ポスト」「フォルダ」) に分ける。
3. **最近保存した 3 件**: 見出しを小さく控えめにする。各行は 1 行に収め、投稿者名 (`@handle`) を薄い色、本文を通常の色にする。長いものは `text-overflow: ellipsis`。`title` 属性に全文を入れる現在の動作は保つ。
4. **ボタン**:
   - 「管理画面を開く」だけを、主な操作として塗りのボタンにする。
   - 「サイドパネルで開く」は、枠のボタン (副の操作)。`hasSidePanel()` が真のときだけ出す、いまの条件は変えない。
   - 「設定」「診断情報をコピー」は、下の行に、小さく並べて置く (2 つを横並び)。
5. 診断の通知 (`HealthNotice`) と、読み込み失敗の表示 (`role="alert"`) の位置と動作は変えない。

## 守ること
- 保存データの形、各ボタンのクリック時の動作 (`openManager`、`openSidePanel` → `window.close()` など) は変えない。
- キーボード操作 (Tab 順は、上から主な操作 → 副の操作 → 設定 → 診断情報) と、`aria-*` を保つ。
- ライト / ダークのどちらでも読める。ポップアップの幅は、いまと同じか、少し広い程度 (320px 前後) にする。
- 必須の権限は増やさない。外部通信もしない。
- 新しい文言が要る場合 (タイル下の「ポスト」「フォルダ」は既存の `popupPosts` / `popupFolders` を再利用)、8 言語すべてに入れる。`npm run release:check` のキーの突き合わせが通ること。使われなくなったキー (`popupAccount` など) は、他で使っていなければ 8 言語から外す。
